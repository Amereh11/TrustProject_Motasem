TRUSTPROJECT_MOTASEM — TERMINAL COMMANDS

FIRST: open Terminal INSIDE the extracted TrustProject_Motasem folder.
(Mac: Terminal, type 'cd ' with a space, drag this folder into Terminal,
then press Return. Windows: use the Ubuntu/WSL terminal in the folder.)

1) START THE LIVE LOCAL SERVER (creates a clean .venv/config if missing):
python3 runner.py start

2) STOP THE LIVE SERVER (after participants have completed their study):
python3 runner.py stop

3) EXPORT ALL DATA (psiTurk raw CSVs + cleaned JASP CSVs):
python3 runner.py export

4) DELETE ALL LOCAL PARTICIPANT RECORDS AND CSV EXPORTS:
# WARNING: This permanently destroys saved study data. Stop server first.
python3 runner.py reset --confirm-reset

5) PRINT THE LINKS:
python3 runner.py link

LIVE LINK — data SAVED to the local database while server is running:
http://127.0.0.1:22362/study

PRACTICE — no data saved, same study screens as live server:
preview.html

Mac and Linux/WSL use python3 for all five commands above.
Windows native: preview.html works, but live psiTurk needs Linux via WSL.
For the first setup install Python 3.9 or uv; internet is required.
